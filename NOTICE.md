# Rights and source availability

This repository contains public documentation, schemas, validation logic, and
sanitized engineering evidence for Deedseal.

The underlying product source — the private execution layer and the private
engineering control plane — is not distributed by this repository. No license
to that private source, its implementation, internal artifacts, names, marks,
or other rights is granted by publication of this material.

Unless a file explicitly states otherwise, all rights not expressly granted are
reserved. Public visibility does not make the underlying product open source.
