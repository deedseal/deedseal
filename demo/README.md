# Demonstration target

This directory holds an illustrative seed contract test for the published demonstration. The runs themselves targeted `app/product/demo/test_demonstration_contract.py`; the publicly checkable run's exact before-and-after bytes are published under `examples/verified/`.

**Two controlled runs have been published; one of them is publicly checkable.** In the publicly checkable run, an AI coding agent, working under an owner-signed work grant, added exactly one new test function, `test_demonstration_marker_is_present`, to a single named file, changing nothing already in it. The accepted run closed into a run passport published at [`examples/verified/run-passport.json`](../examples/verified/run-passport.json), together with the offline verifier ([`tools/verify_run_passport.py`](../tools/verify_run_passport.py)) and a byte-tampered twin of the passport. The run happened in a private engineering repository, so the commit identifiers the passport binds do not resolve here — `git cat-file` on them fails, by design. What a reader can check without leaving this repository is the passport's signature chain and the exact pre-run and post-run bytes of the changed file, published beside it. The second controlled run is recorded separately by `EVD-CORE-0004`; its exact result bytes are at `app/product/demo/test_demonstration_contract.py`, and no passport for it is published. The walkthrough — commands, expected verdicts, and how to make your own tampered twin — is [docs/verify.md](../docs/verify.md).

The seed shipped one passing test, `test_seed_is_present`; it is still here, unchanged. The contract test exists to give a supervised run a small, bounded, byte-checkable thing to change; the size of the change is not the point, the boundedness is. It is not a human contribution surface. Nothing here is product source.

The workstreams that produced this — the public verifier release and the published demonstration — are recorded in [docs/status.md](../docs/status.md); the decision to publish the verifier is [decision 0006](../docs/decisions/0006-publish-the-verifier-under-apache-2.md). What a passport proves — and what it does not — is in [docs/passport.md](../docs/passport.md).
